# 需求与待定设计

本文件记录已读取企划的设计要点及用户在对话中确认的补充，不替代用户原文，也不表示已读取仍在创作的最新草稿。新增玩法须在对应阶段确认。

## 已明确

- 二十年后的未来，少年使用能控制梦境的机器进入异世界战斗，击败最终 Boss 才能醒来。
- 动作肉鸽、回合制、卡牌策略、2D 俯视、像素风、网格战场。
- 局外为鼠标点击操作的多个界面。
- 局内为门相连的多个房间，传送门通往下一层。
- 非战斗时 WASD 移动、字母 O 交互。
- 战斗由指令卡牌驱动；确认前可自由排列、叠加手牌。
- 连招条件以每张卡牌的描述为准。当前狂怒只检查紧邻前牌是否为攻击类型，不要求命中；以后可以有要求上一回合命中并造成伤害的连招，由用户明确设计。
- 能量计划用于角色技能；在完成一名正式角色并完整跑完一局后，再确认具体规则并接入。
- 流逝 n：该牌其他指令结束后，敌方立即行动 n 回合。
- 移动 n：依次选择同行或同列格子形成路线，双击终点，总长度不超过 n，可原地。后续目标以预计移动后位置为基准。撞障碍或敌人则停在前一格并终止后续指令。
- 需要动画。局外为少年，局内角色逐个制作、持续扩展。
- 开局抽5张特殊牌；基础牌无限使用、不消耗、不弃置。抽弃牌堆只含特殊牌，抽完后洗回弃牌堆。
- 托盘最多5张；确认前可取回、修改，前牌修改使后续指向目标失效；确认后不可改牌。
- 每次流逝1，所有敌人依次各行动一次，只显示下一回合意图。攻击分为锁定格与瞄准玩家两种。
- 受击中断时结束玩家指令，进入弃牌阶段。
- 疾行移动3抽1、横砍周围8格之一伤害6、深睡抽3，三者流逝1。横砍打空仍执行。
- 狂怒四邻格各8伤害，接在攻击牌后多造成一次伤害，两次伤害连续结算，然后流逝1；不重复授予霸体。
- 狂怒包含霸体与流逝1指令。霸体是角色状态：受伤仍扣生命，但不因受击中断；所有敌人完成一回合后结束。
- 整局梦境使用持续卡包，获得的特殊牌进入卡包，可通过后续设计的方式删牌。每场战斗结束后手牌、弃牌堆和抽牌堆全部收回卡包；下一场战斗开始时重新洗成抽牌堆，再抽5张特殊牌。此跨战斗卡包规则尚未实现，原型仍在每场战斗初始化10张狂怒。
- 战后奖励暂定随机提供3张特殊牌并选择1张，具体牌池与奖励流程待对应阶段落实。
- 所有正式角色、怪物和卡牌由用户设计，助手可提供建议。数值平衡等用户试玩并指出异常后开展，保留用户原始设计数值作为比较依据。
- 局外完整主界面后续制作，包含角色选择、武器抽取、成就查看、难度选择等；武器机制在项目后期接入。
- 后续增加拖动卡牌放入卡槽；当前通过点击放入，右键查看卡牌详情，托盘牌可在详情中取回。

## 待用户确认

1. 新卡牌各自的连招条件及效果；后续能量来源、上限、技能效果与消耗。
2. 特殊牌正式牌库构成、手牌上限和更多特殊效果。
3. 正式角色、敌人设计、关卡与最终美术规格。
4. 原型中断时未执行牌去向等临时解释见 stage2.md，可在验收时调整。

## 当前阶段范围

前三个阶段均已通过验收。第三阶段 v0.3.1 支持 WASD 网格探索、O 键交互、三个相连房间、庭院原地交战和跨层传送。胜利后在最后战斗格自动恢复 WASD。抽取 n 在该指令执行时立即入手，数量不足时洗回弃牌补抽，仍不足时抽尽现有牌后继续后续指令。
