# 需求与待定设计

本文件记录当前《清醒梦.docx》的设计要点，不替代用户原文。新增玩法须在对应阶段确认。

## 已明确

- 二十年后的未来，少年使用能控制梦境的机器进入异世界战斗，击败最终 Boss 才能醒来。
- 动作肉鸽、回合制、卡牌策略、2D 俯视、像素风、网格战场。
- 局外为鼠标点击操作的多个界面。
- 局内为门相连的多个房间，传送门通往下一层。
- 非战斗时 WASD 移动、字母 O 交互。
- 战斗由指令卡牌驱动；确认前可自由排列、叠加手牌。
- 多张卡牌成功执行可获得连招奖励；受击等判定细节待定。
- 能量通过多种方式获取，用于释放角色技能。
- 流逝 n：该牌其他指令结束后，敌方立即行动 n 回合。
- 移动 n：鼠标选择曼哈顿距离不超过 n 的格子，可选原地，执行到该指令时移动至目标格。
- 需要动画。局外为少年，局内角色逐个制作、持续扩展。

## 待用户确认

1. 同时行动与流逝的关系，以及碰撞、攻击、受击、死亡的结算顺序。
2. 连续移动卡牌的范围以实际位置还是规划后的预计位置计算；障碍、占位、路径与失效目标如何处理。
3. 手牌数量、抽牌时机、弃牌与回收规则，以及卡牌费用。
4. 连招最小卡牌数量、成功与中断条件、奖励内容。
5. 能量来源、上限、技能效果与消耗。
6. 非战斗移动采用自由移动还是网格移动。
7. 角色、攻击规则、敌人行为、关卡规模和最终美术规格。

## 当前阶段范围

阶段一只建立开发环境、项目结构、可运行启动界面和协作记录；以上待定战斗机制暂不实现。
