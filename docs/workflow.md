# 制作流程

1. 阅读最新企划与本地修改，复述阶段范围、目标、工具和验收标准。
2. 用户确认并下达阶段开始指令。
3. 执行已批准工作。缺少工具时提醒并负责安装，确需用户完成的账号或系统操作再单独说明。
4. 检查运行、相关交互及本次改动，提供明确的已完成内容与限制。
5. 清理本阶段临时残留，提交并推送 GitHub，报告版本和结果。
6. 用户试玩验收；收到反馈后修复并再次检查、推送。

## 阶段顺序

1. 开发环境、工程基础、启动界面。
2. 核心网格战斗、指令队列、移动与流逝，确认规则后扩展攻击、连招和能量。
3. 房间探索、交互、门与传送门、探索战斗衔接。
4. 第一个可完整试玩的梦境与 Boss。
5. 美术动画音效完善及更多角色与内容。

每阶段开始前由助手提出具体可运行成果和验收步骤；本顺序是制作路线，不代表后续阶段已获执行授权。
