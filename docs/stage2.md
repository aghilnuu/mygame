# 第二阶段 核心战斗原型

状态：用户已验收通过并授权统一提交推送，第二阶段完成。

## 操作

1. 点击基础牌或特殊手牌。疾行、横砍需要在网格上指定目标。
2. 疾行单击同行或同列的格子形成路线，累计最多3格；双击终点或点“完成路线”。原地也可。右键撤销一步。
3. 托盘最多5张。左键指向牌重选目标，点击狂怒查看四邻格攻击范围。右键任意卡牌查看内容；托盘牌的详情窗口提供“取回此牌”。仅查看或确认相同目标不影响后牌，实际修改前牌后才要求后续指向牌重新指定。
4. 确认后整组锁定，观察指令与敌人穿插行动。结束后可以再次规划。
5. 下方特殊手牌支持横向滚动。右侧显示牌堆数量、洗牌次数、敌方意图和行动日志。点击敌人头顶的“移／锁／追”查看详细意图，橙框是锁定攻击格。
6. 移动终点以小圆点标记；选择或点击攻击牌时显示可选目标范围，已确定的横砍目标显示圈与叉号。

## 原型临时配置与解释

- 玩家30生命，两名敌人各24生命、攻击3伤害。固定按守望者、追猎者顺序行动。
- 测试牌库10张狂怒，开局抽5张。基础牌无限使用。特殊手牌暂不设上限。
- 按最新企划，狂怒本体流逝1，附带霸体。横砍和狂怒均属于攻击牌；紧接攻击牌时追加一次流逝0的狂怒，仍包含再次进入霸体与四邻格各8伤害，不触发额外敌方回合，不消耗另一张手牌。
- 打空暂不触发连招中断。无霸体时受击会终止后续玩家指令；路径阻挡仍然中断移动，霸体不能穿过障碍。
- 霸体不以卡牌结束或玩家规划阶段为解除条件，而是在完整敌方回合结束时解除。狂怒本体的流逝1触发该回合；流逝0的连招追加重新给予霸体并保留至下一次敌方回合结束。重复获得不叠加回合数，敌人只移动或攻击打空也会在该回合结束时解除。生命归零仍然失败。
- 未执行的特殊牌在中断时暂定返还手牌；已执行特殊牌在本组结束时弃置；未出牌手牌保留。
- 受击后停止玩家后续指令，已触发的敌方回合仍让其余存活敌人各行动一次；玩家死亡则立即结束。
- 移动受阻时停止在前一格，取消该牌剩余抽牌、流逝及后续卡牌。
- 抽牌堆耗尽时洗回弃牌堆；两个牌堆都为空时停止抽牌。执行中抽到的牌留待下一次规划。
- 敌人攻击距离暂定周围8格。守望者锁定格，追猎者行动时瞄准玩家。超距攻击打空；远离时显示移动意图并寻路前进一格。
- 临时数值和未执行牌处理等细节可在验收时调整。能量与通用连招奖励待定，本版已实现狂怒的具体连招奖励。

## 验收示例

1. 开战应有5张狂怒、抽牌堆5、弃牌堆0。
2. 疾行后放横砍，其目标范围以移动终点计算；改疾行后横砍变为待指定。
3. 初始位置横砍右侧空格，再放狂怒：横砍打空，敌人移动靠近，狂怒追加一次，共16伤害。
4. 对比疾行离开锁定格和深睡停留的结果，观察打空、受击与中断。
5. 路线经过障碍时停在前格并中断。使用特殊牌后反复抽牌，观察弃牌洗回。
6. 击败所有敌人或生命归零时显示结果，可重新开始或返回菜单。
