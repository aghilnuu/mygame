# 开发记录

## 0.1.0 阶段一

- 经用户确认开始检查并安装第一阶段工具。
- 检查 Git、已有仓库及常见引擎安装位置。
- 从官方来源安装 Godot 4.7.2 标准版，验证 SHA-512 校验与版本输出。
- 创建 Godot 工程、Compatibility 渲染配置和中文启动界面。
- 建立需求、待定设计、协作流程、环境说明及缓存忽略规则。
- 进入梦境按钮暂不可用，退出按钮可用；战斗和房间探索等待后续阶段确认。

验证结果：

- 官方 SHA-512 校验通过；引擎输出 `4.7.2.stable.official.ed1daf0bf`。
- 无窗口模式导入工程成功，未报告脚本或场景解析错误。
- 启动场景运行成功，输出 `LUCID_DREAM_STARTUP_OK`。
- 实际窗口使用 NVIDIA 显卡的 OpenGL Compatibility 渲染成功；人工查看截图确认中文、标题、按钮与背景布局正常。
- 点击退出按钮后窗口与引擎进程正常关闭。
- 已创建“清醒梦 启动”“清醒梦 编辑器”桌面快捷方式。
- 工程缓存保留供编辑器复用并由 Git 忽略；下载用的临时安装包在校验与验证后清理。
