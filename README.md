# 清醒梦

2D 俯视像素风网格战斗游戏，结合指令卡牌、连招、能量与肉鸽探索。

当前版本为 **0.2.0 核心战斗原型（已验收）**：点击“进入梦境”试玩指令规划、基础卡牌、狂怒连招和敌方行动。采用占位美术。操作说明及临时测试规则见 [第二阶段说明](docs/stage2.md)。第二阶段已完成，后续阶段另行确认。

## 打开与运行

使用 **Godot 4.7.2 标准版**导入根目录的 `project.godot`，按 **F6 运行当前场景**或 **F5 运行项目**。也可使用本机桌面的“清醒梦 启动”和“清醒梦 编辑器”快捷方式。

工具入口：`tools/launch.ps1` 运行游戏，添加 `-Editor` 打开编辑器。引擎安装说明见 [开发环境](docs/environment.md)。

## 目录

- `清醒梦.docx`：用户维护的游戏企划原件。
- `scenes/`：Godot 场景。
- `scripts/`：GDScript 代码。
- `assets/`：后续图片、声音、字体等资源。
- `data/`：后续角色、卡牌和敌人数据。
- `docs/`：需求、环境和开发记录。
- `tools/`：本地开发入口。
