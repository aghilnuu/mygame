# 清醒梦

2D 俯视像素风网格战斗游戏，结合指令卡牌、连招、能量与肉鸽探索。

当前版本为 **0.3.0 房间探索与战斗衔接原型**。从标题选择“进入梦境”，用 WASD 逐格移动。在门、梦魇或星门的上下左右相邻格按字母 O 交互。

从入梦回廊的东门进入回声庭院，靠近中央的梦魇并迎战。胜利后点击“继续探索”，东门解封。进入星门之间，在星门旁按 O 抵达下一层。已清除的庭院可以自由往返。本版各层复用三种房间，生命跨房间与楼层保留，每场战斗独立准备测试牌库。战斗操作见 [第二阶段说明](docs/stage2.md)。

## 打开与运行

使用 **Godot 4.7.2 标准版**导入根目录的 `project.godot`，按 **F6 运行当前场景**或 **F5 运行项目**。也可使用本机桌面的“清醒梦 启动”和“清醒梦 编辑器”快捷方式。

工具入口：`tools/launch.ps1` 运行游戏，添加 `-Editor` 打开编辑器。引擎安装说明见 [开发环境](docs/environment.md)。

## 目录

- `清醒梦.docx`：用户维护的游戏企划原件。
- `scenes/`：Godot 场景。
- `scripts/`：GDScript 代码。
- `assets/`：后续图片、声音、字体等资源。
- `data/`：后续角色、卡牌和敌人数据。
- `docs/`：需求、环境和开发记录。
- `tools/`：本地开发入口。
